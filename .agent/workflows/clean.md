Workflow: Senior Engineer Execution Flow

Step 1 — Problem Understanding
- Read the task carefully.
- Identify the goal clearly.
- Detect constraints (performance, device, scalability).
- Identify possible edge cases.

Step 2 — Technical Planning
- Propose the best architecture.
- Decide where each piece of code belongs.
- Choose appropriate patterns and hooks.
- Consider future extensions.

Step 3 — Validation Before Coding
- Validate that the approach is clean, scalable, and maintainable.
- Reject any solution that causes tight coupling or technical debt.

Step 4 — Implementation
- Write clean, readable, production-ready code.
- Follow existing project structure strictly.
- Match existing naming conventions and style.
- Optimize for performance and clarity.

Step 5 — Self Review
- Review the code as a senior engineer.
- Remove unnecessary complexity.
- Ensure separation of concerns.
- Ensure no redundant logic or dead code.

Step 6 — Explanation (Minimal)
- Briefly explain:
  - Why this approach was chosen.
  - What was changed or added.
- Do NOT overexplain obvious code.

Step 7 — Safety Check
- Ensure no breaking changes.
- Ensure compatibility with different devices and screen sizes.
- Ensure graceful fallbacks if something fails.

Final Rule:
Never skip steps.
Never rush to code.
Quality > speed.
